# M4 inference benchmark (CPU)

Generated by `python scripts/benchmark_inference.py run` (`make benchmark`); raw numbers in `reports/m4/results/benchmark.json`, run logged in `reports/experiments/m4/benchmark.csv` (run_id `b18c2967e62e`). Requests are 1000 val narratives (seeded sample, mean 183 words); in-process timing, no HTTP (see `reports/m4/api_latency.md` for the API).

Machine: macOS-13.7.8-arm64-arm-64bit, 8 logical CPUs, 8 GB RAM, Python 3.11.15. Single machine, single run: treat as indicative.

## Primary model as served: `baseline/tfidf_sgd_alpha2e-6_conv` (`baseline-tfidf_sgd_alpha2e-6_conv-80a3ba969565-cal`)

Calibrated `BaselinePredictor.predict` (vectorize + product, issue, priority + temperature) for single requests; vectorize + 3x predict_proba for batches.

| mode | p50 ms | p95 ms | p99 ms | mean ms | throughput (req/s) |
|---|---|---|---|---|---|
| single (batch 1) | 10.77 | 11.51 | 12.22 | 10.83 | 92.3 |
| batch 8 (per batch) | 12.29 | 13.88 | 14.47 | 12.43 | 643.4 |

- Model size on disk: **41.5 MB** (vectorizer + 3 classifiers, joblib).
- RSS increase when loading: **187 MB**; load time 0.9 s. Peak RSS of the benchmark process (includes val text and the other models): 1091 MB.
- SPEC B7 target p95 <= 300 ms on CPU: single-request p95 11.51 ms (meets).
- Cost per 1k requests (assumption-based): 10.83 ms mean CPU time per request = 10.83 CPU-seconds per 1k requests on one core; a price per CPU-hour is needed to turn this into money (TODO: team assumption).
