# M4 robustness (validation split)

Generated by `python -m complaintiq.eval.robustness run` (`make robustness`). The test split was not read.

- Model `baseline/tfidf_sgd_alpha2e-6_conv` (model_version `baseline-tfidf_sgd_alpha2e-6_conv-80a3ba969565`, data_version `80a3ba969565`).
- Rows: a seeded (seed 42) val subsample of 39,983 rows, stratified on issue_class (every class kept). Clean and perturbed scores use the same rows and the same label set (classes with support in the subsample), so the drop is paired.
- drop = clean macro-F1 minus perturbed macro-F1 (positive = worse). flip_rate = share of rows whose predicted label changed.
- Every row below is a logged run in `reports/experiments/m4/robustness.csv` (notes start with `robustness`).

Perturbations: typos edit the given share of letters (delete, substitute, swap, insert); truncation keeps the first N words; sentence shuffle permutes sentences; boilerplate adds a fixed prefix ("I am writing to file a formal complaint and request your assistance.") and suffix ("Please review this matter and respond as soon as possible. Thank you for your time."); lowercase lowercases (the vectorizer already lowercases, so this is a sanity check that should show zero drop); redaction replaces 10% of the remaining words with the placeholder.

Not run (SPEC C6 lists them): paraphrase (needs a paraphrase model) and unseen company names (narratives rarely name the company after CFPB redaction). TODO.
