# M3 model comparison (validation split)

Generated by `python scripts/compare_runs.py` from `reports/experiments/*.csv`. Every number is copied from a logged run; empty cells were not logged. All metrics are on **val**; the test split is not used in M3.

- **`val_macro_f1`** is the mean F1 over the classes with val support (a fixed label set). `val_macro_f1_all_labels` also counts classes that are only predicted (product OTHER has no val rows). Rows logged before this definition was fixed are **superseded** by rescore rows (same saved model, no retraining, notes `rescored: fixed label set`) and are listed separately, never ranked.
- Product and issue use argmax predictions. For priority, macro-F1 uses the fixed threshold 0.5; PR-AUC is threshold-free.
- `converged` = the SGD tolerance stop fired before `max_iter`. `no (hit cap)` = sklearn ConvergenceWarning (or n_iter = max_iter for rows logged before this was recorded). `n/a` = not an iterative model (Complement NB).
- delta = run minus the current `baseline/tfidf_sgd` row with the same task and n_train.
